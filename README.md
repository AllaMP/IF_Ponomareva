## Автотесты Jira Ifellow

Этот проект содержит автотесты для проверки функциональности личного кабинета Jira Ifellow. Тесты охватывают ключевые 
сценарии работы с задачами, такие как аутентификация, создание задач, изменение статусов и проверка данных.

## Используемые технологии

- Язык программирования: Java 17
- Версия: 17.0.12 (LTS)
- Сборка и управление зависимостями: Apache Maven
- Фреймворк для тестирования: JUnit 5
- Автоматизация веб-тестов: Selenide
- Фреймворк для отчетов: Allure Framework

## Браузеры и драйверы

- Mozilla Firefox 
  - version **135.0**
  - geckodriver **0.35.0**
- Google Chrome 
  - version **133.0.6943.54s**
  - chromedriver **33.0.6943.53**

## Настройка окружения

1. Убедитесь, что у вас установлены:
- Java 17
- Apache Maven
- Браузеры (Firefox и Chrome) и соответствующие драйверы (Geckodriver и Chromedriver).
2. Клонируйте репозиторий:
````bash
  git clone https://github.com/AllaMP/IF_Ponomareva.git
````
3. Перейдите в директорию проекта
````bash
   cd IF_Ponomareva
````
4. Запустите тесты (см. раздел "Запуск тестов и формирование отчетов").


## Структура проекта
Проект имеет следующую структуру:
- src/main/java/UI_IF/pages - Page Object
- src/main/java/UI_IF/utils - содержит классы для настройки проекта
- src/test/java/UI_IF/testPage - класс запуска автотестов
- src/test/java/UI_IF/webHooks - содержит класс с настройками действий, которые выполняются до или после тестов, 
а также настройки окружения.
- src/test/resources - файлы конфигурации и отчетов

## Сценарии тестирования
1. Аутентификация пользователя 
   - Проверка успешного входа в личный кабинет пользователя.
2. Переход в проект "Тест"
   - Проверка успешного перехода в проект "Тест".
3. Создание бага и счетчик задач
   - Создание новой задачи типа "bug" и проверка счетчика задач с данным типом.
4. Изменение статуса задачи
   - Проверка изменения статуса задачи.
5. Проверка задачи "TestSeleniumATHomework"
   - Проверка статуса и версии задачи.

## Запуск тестов и формирование отчетов
 
- для запуска тестов выполнить команду:
````bash 
    mvn clean test
````
- для формирования отчета выполнить команду: 
````bash
    mvn allure:report
````
- для просмотра отчета в браузере выполнить команду:
````bash 
    mvn allure:serve
````
